# Studio Atitude — Landing Page

Site oficial do Studio Atitude, o braço de design gráfico da Igreja.

## Deploy

Este projeto está hospedado no [Vercel](https://vercel.com). Para subir a sua própria versão:

1. Faça fork ou clone este repositório
2. Acesse [vercel.com](https://vercel.com) e clique em **Add New → Project**
3. Importe este repositório do GitHub
4. Clique em **Deploy** — sem nenhuma configuração extra

O Vercel detecta automaticamente que é um site estático e faz o deploy em segundos.

## Personalização

- **Email de contato:** troque `studio@atitude.com` no `index.html` pelo e-mail real
- **Estatísticas:** atualize os números na seção "Sobre" conforme a realidade
- **Cores:** o acento laranja está definido como `--orange: #E87722` no CSS

## Tecnologia

HTML + CSS puro. Zero dependências, zero build step. Carrega rápido em qualquer dispositivo.
